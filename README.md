# Music Standardizer

Cleans up and standardizes music file names and tags (Python, with GUI).

![Music Standardizer screenshot](<Music Standardizer - screenshot.png>)

## Run it

**Windows:** double-click `Start Music Standardizer.bat`. If Python or its add-ons (mutagen, plus optional drag-and-drop, preview and album-art helpers) are missing, a box offers to install them for you, then the app opens.

**Other systems:**
```
pip install mutagen tkinterdnd2 pygame pillow
python3 music_standardizer.py
```

The full guide is in `Music_Standardizer_Manual.pdf`.
